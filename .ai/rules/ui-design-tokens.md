# JobFlow UI design tokens

Use the shared JobFlow design tokens in `resources/css/app.css` for all first-party UI work. Prefer semantic tokens over raw palette values or ad hoc typography, radii, and shadows; preserve light/dark support, semantic status colors, and mobile-first sizing.

Extend the shared token system when a reusable design value is missing. Apply this rule to new and existing UI. Do not restyle generated Wayfinder or third-party vendor code.
